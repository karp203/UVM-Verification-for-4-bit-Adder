4-Bit Adder Verification using UVM

## Overview

This project implements a UVM-based verification environment for a simple 4-bit binary adder using SystemVerilog.

The 4-bit adder accepts two 4-bit input operands and produces the corresponding addition result. The UVM testbench generates randomized input combinations, drives them to the adder DUT, monitors the output, and performs automated functional checking using a scoreboard.

## 4-Bit Adder Design

The adder operates on two 4-bit input operands:

- **`a[3:0]`** — First 4-bit operand
- **`b[3:0]`** — Second 4-bit operand
- **`y[4:0]`** — 5-bit addition result

A 5-bit output is required because adding two 4-bit numbers can produce a carry beyond the most significant bit.

```
Input A : 4 bits
Input B : 4 bits
Output Y: 5 bits

Maximum:
1111 + 1111 = 11110
  15 +  15  =   30
```

Therefore, the output range is:

```
0 ≤ A ≤ 15
0 ≤ B ≤ 15
0 ≤ Y ≤ 30
```

## UVM Verification

The verification environment follows a standard UVM architecture:

```
Sequence
   ↓
Sequencer
   ↓
Driver
   ↓
4-Bit Adder DUT
   ↓
Monitor
   ↓
Scoreboard
```

The sequence generates different combinations of the two 4-bit operands. The driver applies these operands to the DUT, while the monitor observes the resulting output.

The scoreboard calculates the expected result independently and compares it with the DUT output.

## Verification Methodology

The project uses the following UVM components:

- **Transaction / Sequence Item** — Represents one addition operation containing the input operands and output result.
- **Sequence** — Generates randomized values for the two 4-bit operands.
- **Sequencer** — Supplies transactions from the sequence to the driver.
- **Driver** — Drives the input operands onto the adder interface.
- **Monitor** — Samples the input operands and DUT output and converts them into transactions.
- **Scoreboard** — Calculates the expected sum and compares it with the DUT output.
- **Agent** — Contains the sequencer, driver, and monitor.
- **Environment** — Instantiates and connects the UVM verification components.
- **Test** — Controls the simulation and starts the required sequence.

## Functional Checking

For every transaction, the scoreboard independently calculates:

```
Expected Result = A + B
```

The expected result is then compared with the output generated by the DUT:

```
             A ─────┐
                    │
                    ├──→ 4-Bit Adder ──→ Y
                    │
             B ─────┘

Scoreboard:
Expected Y = A + B
             ↓
Compare with DUT Y
             ↓
         PASS / FAIL
```

If the DUT output matches the expected result, the transaction passes. If the values differ, the scoreboard reports a verification error.

## Stimulus

The UVM sequence can generate randomized combinations of the two 4-bit operands.

The input space contains:

```
A : 16 possible values
B : 16 possible values

Total combinations = 16 × 16 = 256
```

Thus, the verification environment can exercise all possible input combinations of the 4-bit adder.

The project was developed using **SystemVerilog and UVM** and simulated using **AMD Xilinx Vivado Simulator (XSim)**.

The testbench generates addition transactions and automatically compares the DUT result against the expected value calculated by the scoreboard.
